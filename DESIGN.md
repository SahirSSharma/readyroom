# Readyroom design

Direction selected autonomously under the user's explicit instruction to proceed in one go. Mode: Operate. This is an atelier's fitting desk, with the garment photography doing the work.

Light paper-white background, ink typography, a decisive cobalt accent, pale blue fitting-room panel. No glossy gradients or decorative dashboards. Use a large photographic stage on the left and a clean garment rack on the right. A compact top navigation switches Fitting room, Pickup desk, and About. The main headline is practical: "One piece. A new possibility." The photograph, not a marketing scroll, is the first viewport's focus.

Typography: Manrope for headings and body, sourced via a bundled font package or local files. Bold large headings with tight but readable spacing. Body at least 15px. One radius system (12px surfaces, 8px inputs), generous gutters, fine neutral rules, no nested card shells. Material garment details and stock status are visible without opening dialogs.

Signature interaction: choose a blazer and the same large portrait transitions from source outfit to the actual YouCam result; an accessible before/after control keeps the base outfit within reach. Rendering shows honest status and preserves the source photograph.

Mobile stacks portrait before garments, with no hover-only controls and a reachable primary action. Explicit keyboard focus, reduced motion, clear inline loading/error/empty states. Sample inventory and generated sample photographs are visibly labeled. Details are not sizing promises.
